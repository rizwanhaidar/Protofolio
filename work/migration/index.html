Context

A client was moving its legacy warehouse into Teradata. Over a thousand SQL and PL/SQL artifacts had to be analysed and converted, and the loaded data checked.

My work

I co-developed a migration framework that moved 500+ GB from legacy systems into Teradata. I built Python tooling that analysed 1,000+ SQL and PL/SQL artifacts, cutting migration analysis time by ~40%, and automated repetitive migration steps, reducing manual effort by ~45% (50+ hours a week). I also contributed to dbt and Databricks proofs of concept.

03

Result

A faster, more repeatable migration path, with analysis and loading steps that no longer depended on manual work.
