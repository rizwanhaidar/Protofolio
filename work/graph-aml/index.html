Graph ML · CASE STUDY

University of Bonn

Graph learning for anti-money laundering.

Which graph-learning choices detect rare illicit transactions best? We compared five approaches on one benchmark under one protocol.

Team lab · Information Retrieval in Practice · with Avin Safari Shirzi, Mohamed Abouelella and Haofan Wen

Best F1 77.6% across 5 approaches
AMLworldGraph neural networksGraph transformersPyTorch GeometricMinority-class F1

IN THIS PROJECT

QuestionApproachResultNext steps
01

Question

Which architectural choices improve edge-level money-laundering detection under extreme class imbalance, and how reproducible are published results?

02

Approach

We modelled AMLworld transactions as a directed multigraph and compared Multi-GNN, a FRAD-DM-inspired feature reconstruction, FraudGT, D-EMAML and C2GAT. Every approach used the same chronological split and reported minority-class F1 at the best-validation checkpoint, averaged over five seeds.

03

Result

The reproduced FraudGT baseline matched its published score (76.4%). Adding flow-conservation attention and temporal edge features raised minority-class F1 to 77.6% without adding parameters. Hand-derived edge features alone did not improve the Multi-GNN baseline.

04

Next steps

Controlled ablations of each design choice, and hybrid models combining causal temporal context with transformer-style neighbourhood encoders.
